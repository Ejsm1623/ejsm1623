## ✨ Proyectos destacados

### 🚗 Pacific Fast Car

**Web bilingüe en producción** para una empresa de alquiler de vehículos en Panamá.

**Funcionalidades:**

- Sitio en español e inglés.
- Catálogo de vehículos con filtros y características.
- Consultas de disponibilidad por WhatsApp.
- Formulario de contacto por correo mediante una API SMTP.
- Contenido organizado mediante colecciones de Astro.
- Sistema de diseño con componentes y tokens reutilizables.

**Mi participación:**

- Diseño de interfaces responsivas tomando Figma como referencia.
- Desarrollo e implementación del sitio.
- Configuración de correo empresarial y DNS.
- Implementación de SEO básico y ajustes de rendimiento.

**Stack:** Astro · Tailwind CSS · JavaScript · TypeScript · Nodemailer · Vercel

**Aprendizajes:** generación estática con Astro, organización de contenido bilingüe y uso de una función de servidor para el envío de correo.

🔗 [Visitar Pacific Fast Car](https://www.pacificfastcar.com/es/)

### 💼 JasaJob

**Web corporativa en producción** para una empresa de servicios de recursos humanos.

**Funcionalidades:**

- Presentación de servicios de reclutamiento y consultoría.
- Sección de vacantes.
- Contenido administrado desde WordPress.
- Canales de contacto para empresas y candidatos.

**Stack:** Astro · Tailwind CSS · TypeScript · WordPress headless · Vercel

🔗 [Visitar JasaJob](https://www.jasajob.com/)

### 🌿 Cabañas de Asgard

**Web de alojamiento en producción** para un negocio turístico en Panamá.

**Funcionalidades:**

- Presentación de cabañas, instalaciones y comodidades.
- Galería de imágenes y servicios complementarios.
- Contenido administrado desde WordPress.
- Acceso al proceso de reserva del alojamiento.

**Stack:** Astro · Tailwind CSS · TypeScript · WordPress headless · Vercel

🔗 [Visitar Cabañas de Asgard](https://www.xn--cabaasdeasgard-tnb.com/)
