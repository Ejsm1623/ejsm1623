## Proyectos seleccionados

### 🚗 Pacific Fast Car
Web bilingüe para una empresa de alquiler de vehículos en Panamá.

- Presentación de la flota y características de los vehículos.
- Versiones en español e inglés.
- Consultas de disponibilidad por WhatsApp.
- Catálogo organizado mediante colecciones de contenido.
- Componentes visuales basados en un sistema de diseño.

**Tecnologías:** Astro · Tailwind CSS · TypeScript · Vercel

[Visitar Pacific Fast Car](https://www.pacificfastcar.com/es/)

### 💼 JasaJob
Web corporativa para una empresa de servicios de recursos humanos.

- Presentación de servicios de reclutamiento.
- Consulta de vacantes.
- Contenido administrado desde WordPress.
- Canales de contacto para empresas y candidatos.

**Tecnologías:** Astro · Tailwind CSS · TypeScript · WordPress headless · Vercel

[Visitar JasaJob](https://www.jasajob.com/)

### 🌿 Cabañas de Asgard
Web para un negocio de alojamiento en Panamá.

- Presentación de cabañas, instalaciones y comodidades.
- Galería y servicios complementarios.
- Contenido administrado desde WordPress.
- Acceso al proceso de reserva del alojamiento.

**Tecnologías:** Astro · Tailwind CSS · TypeScript · WordPress headless · Vercel

[Visitar Cabañas de Asgard](https://www.xn--cabaasdeasgard-tnb.com/)
